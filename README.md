# Python Calculator

A modern calculator built using Python and Tkinter.

## Features

- Modern Dark UI
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Positive/Negative
- Backspace
- Keyboard Support
- Error Handling

## Technologies Used

- Python 3
- Tkinter

## Run

```bash
python calculator.py
```
